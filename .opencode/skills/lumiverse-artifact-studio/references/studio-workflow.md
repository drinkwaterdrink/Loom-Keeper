# Artifact Studio Workflow

## 1. Intake

Capture:

- concept
- target user
- desired Lumiverse surfaces
- existing inputs
- whether output should be code, content, JSON, or all of them

## 2. Product Shape

Decide whether the concept should become:

- Spindle extension
- pack
- preset/world book set
- character/persona import
- hybrid bundle

## 3. Bundle Files

Create:

```text
00-brief.md
01-architecture.md
02-spindle-extension.md
03-pack-lumia-blueprint.md
04-preset-worldbook-plan.md
05-json-manifest.md
06-validation.md
07-ai-builder-prompt.md
drafts/
```

## 4. Cross-Surface Design

Make each surface do one job:

- Spindle: code, UI, storage, live tools.
- Pack: Lumias, Loom content, declarative Council tools.
- Preset: durable prompt architecture.
- World book: triggered lore/knowledge.
- Character/persona: identity data.

## 5. Validation

Every bundle needs:

- build/import plan
- prompt behavior checks
- pack schema confidence
- permission list
- failure behavior
- evaluator pass
