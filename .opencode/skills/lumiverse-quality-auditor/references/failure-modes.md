# Lumiverse Failure Modes

## Critical

- Backend bundle contains blocked system APIs.
- Extension broadcasts private user state.
- Manifest entry points do not exist.
- Raw pack JSON uses unverified/invalid field names.
- Importer overwrites user data without backup.

## High

- Overbroad permissions scare users or fail review.
- Interceptor slows every generation.
- Quiet generations are accidentally modified.
- UI requires desktop width.
- Spindle tool relies on spoofable userId args.
- ST DOM patch remains in converted code.

## Medium

- Lumia has flavor but no advisory function.
- Council tool output is too long for value.
- World book entries trigger too broadly.
- Prompt blocks duplicate authority.
- Settings fail to degrade when permission revoked.

## Low

- Naming inconsistency.
- Missing diagnostics.
- Weak README/user instructions.
- Non-critical style polish.
