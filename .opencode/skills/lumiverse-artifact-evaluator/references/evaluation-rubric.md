# Lumiverse Evaluation Rubric

Score each dimension 0-10.

| Dimension | What to inspect |
| --- | --- |
| Purpose clarity | The artifact has a clear job and target workflow |
| Lumiverse-native fit | Uses correct surfaces instead of ST habits |
| Council usefulness | Advisors/tools give actionable pre-generation value |
| Prompt reliability | Instructions trigger when intended and avoid conflicts |
| Token economy | Context cost is justified |
| Distinctiveness | Lumias/modules are not redundant |
| Safety/import/build | Schema, permissions, scanner, and import risks are controlled |
| User ergonomics | UI/settings/workflow are usable, including mobile |
| Failure behavior | Missing permissions/schema/API errors degrade gracefully |

## Thresholds

- 90-100: ready or close to ready.
- 75-89: strong, needs targeted polish.
- 60-74: promising but structural fixes needed.
- 40-59: concept works, execution is brittle.
- below 40: redesign before building.
