# Lorebook Pack Recipe

## ST Pattern

World Info/lorebook JSON with keys, selective keys, probability, depth, and recursion.

## Lumiverse Target

- Lumiverse World Book.
- Entries mapped to `key`, `keysecondary`, `content`, `comment`, `position`, `depth`, `selective`, `constant`, `probability`, `sticky`, `cooldown`, `delay`.
- Attach to character via `world_book_ids` when character-specific.

## Rules

- Tighten broad keys.
- Split multi-topic entries.
- Validate activation.
